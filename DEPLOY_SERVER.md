# Инструкция по деплою на сервер

## После пуша изменений в git:

### 1. Подключиться к серверу:
```bash
ssh ваш_пользователь@moisei.uk
# или
ssh ваш_пользователь@IP_адрес_сервера
```

### 2. Перейти в директорию проекта:
```bash
cd /path/to/moisei
# или где у вас находится проект
```

### 3. Обновить код из git:
```bash
git pull origin master
# или
git pull origin main
```

### 4. Очистить кеш (если используется):
```bash
# Если используете nginx с кешированием:
sudo systemctl reload nginx

# Если используете Cloudflare или другой CDN:
# Очистите кеш через панель управления CDN
```

### 5. Проверить что файлы обновились:
```bash
# Проверить что index.html обновлен:
grep "google-ads" index.html

# Проверить что favicon имеет версионирование:
grep "favicon.*v=20250111" index.html
```

### 6. Очистить кеш браузера (для тестирования):
- Chrome: Ctrl+Shift+Delete (Windows) или Cmd+Shift+Delete (Mac)
- Или используйте режим инкогнито для проверки

### 7. Проверить favicon:
- Откройте сайт в браузере
- Проверьте что favicon отображается
- Если нет - очистите кеш браузера или используйте: `https://moisei.uk/favicon.ico?v=20250111`

## Важно:
- Все изменения временные для Google Ads
- После запуска рекламы нужно вернуть все обратно (см. TEMP_GOOGLE_ADS_CHANGES.md)
